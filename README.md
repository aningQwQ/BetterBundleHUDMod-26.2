# Better Bundle

为《我的世界》收纳袋（Bundle）添加一个可快速访问、整理与塞入的侧边面板。

- 客户端 Mod（仅 `client` 环境），不修改服务端
- 目标版本：Minecraft **26.2** / Fabric

---

## 功能

### 侧边面板
- 在背包/容器界面左侧显示收纳袋内容面板，可通过右上角的收纳袋图标按钮独立开关。
- 面板显隐只由开关控制：即使身上没有袋子也会显示（空面板 + 计数 `0/0`）。
- 分类栏：全部 / 方块 / 植物 / 食物 / 工具装备 / 杂物 / 矿物 等。
- 搜索栏（仅“全部”分类下可交互，支持拼音）。
- 面板条目**按物品 id 稳定排序**（显示顺序与物理存放位置无关），方便记忆位置、快速取用。

### 快速存取
- **空格 + 点击物品槽**：把该物品存入收纳袋。
- **空格 + 按住拖拽**：批量存入经过的多个槽位。
- **点击面板中的物品**：光标为空时取出到光标。
- **Shift + 点击面板物品**：取出并放入空槽（打开的容器优先，其次玩家背包）。
- **光标持物点击面板**：把光标物品存入收纳袋。

### 跨袋分发（同类聚拢）
单袋放不下时自动拆分到多个袋子，尽量聚堆：
1. 优先放入**已有同种物品**的袋子；
2. 没有同种时，放入**当前空余最大**的袋子；
3. 装不下的剩余部分继续放入下一个袋子。

### 一键整理
- 面板底部的「一键整理」按钮，整理**袋内已有物品**（不收纳背包散落物）。
- 目标：**同类聚拢 + 尽量填满**。装箱规则（与写入一致）：
  1. 满堆切块（同一物品切成 `maxStack` 一个的块）；
  2. 每块**优先放入当前已含有该物品、且放得下的袋子**（聚堆、少动）；
  3. 没有这样的袋子时，放入**当前空余最大**的袋子。
- 特性：**幂等**——整理完再点基本 `0` 步（不会反复倒腾）。
- 执行安全：
  - 整叠取出/放入，逻辑动作间隔 **2~5 tick**；
  - 每个动作等待服务端把源袋/目标袋更新为预期内容后才继续（防幽灵物品）；
  - 超过 **1 秒**未确认则熔断并按历史反向回滚；
  - **玩家任意输入立即中止**（不回滚）；进度显示在按钮上；
  - 当前已达标时提示「无需整理」；有差异但推不动时提示「空间不足或受限」。

### 容量显示
- 面板右下角显示 **已用 / 总量**：
  - 已用 = 各袋已用重量之和（单位 1/64）；
  - 总量 = 袋子数量 × 64，**恒定**，不随放入 16 堆叠/不可堆叠物品而变化。

### 创造模式
- 创造背包界面（`ItemPickerMenu`）下：
  - **整个面板不绘制**，仅在开关打开时显示「创造模式不支持此功能」；
  - **保留右上角面板开关**，可正常开/关；
  - 其余交互（分类/搜索/面板点击/取出/塞入/批量）**全部禁用**。
- 创造玩家打开箱子等普通容器不受影响。

## 环境要求

| 组件 | 版本 |
|---|---|
| Minecraft | 26.2 |
| Fabric Loader | >= 0.19.3 |
| Fabric API | 0.153.0+26.2 或兼容版本 |
| Java | >= 25 |

---

## 安装

1. 安装 Fabric Loader（>= 0.19.3）。
2. 将 [Fabric API](https://modrinth.com/mod/fabric-api) 与 `better-bundle-<version>.jar` 放入 `.minecraft/mods/`。
3. 启动游戏（仅客户端需要安装）。

发行版下载：见仓库的 **Releases** 页面。

---

## 从源码构建

```bash
./gradlew build
```

产物位于 `build/libs/`：

- `better-bundle-<version>.jar` — 安装用
- `better-bundle-<version>-sources.jar` — 源码

开发运行：

```bash
./gradlew runClient
```

---

## 已知限制

- 一键整理只重排**袋内物品**，不会把背包散落物品收进袋子（散落物品请用「空格+点击 / 面板塞入」）。
- 同类物品总量超过单袋上限时会跨多袋（物理必然）。
- 内嵌收纳袋（袋中之袋）视为不可动障碍，且占用目标袋容量。
- 极紧空余、需大量搬动的场景动作会较多（每个动作需服务端确认与限速）。
