# Better Bundle

为《我的世界》收纳袋（Bundle）添加一个可快速访问、整理与分发的侧边面板。

- 客户端 Mod（仅 `client` 环境），不修改服务端
- 目标版本：Minecraft **26.2** / Fabric

---

## 功能

### 侧边面板
- 在背包/容器界面左侧显示收纳袋内容面板，可通过右上角的收纳袋图标按钮独立开关。
- **面板显隐只由开关控制**：即使身上没有袋子也会显示（空面板 + 计数 `0/0`），避免“部分组件消失”的困惑。
- 分类栏：全部 / 方块 / 植物 / 食物 / 工具装备 / 杂物 / 矿物 等。
- 搜索栏（仅“全部”分类下可交互，支持拼音）。

### 快速存取
- **空格 + 点击物品槽**：把该物品快速存入收纳袋。
- **空格 + 按住拖拽**：批量存入经过的多个槽位。
- **点击面板中的物品**：光标为空时取出到光标。
- **Shift + 点击面板物品**：取出并放入空槽（打开的容器优先，其次玩家背包）。
- **光标持物点击面板**：把光标物品存入收纳袋。

### 跨袋分发（XFS 聚堆）
单袋放不下时自动拆分到多个袋子，尽量聚堆：
1. 优先放入已有同种物品的袋子（同种越多越优先）；
2. 没有同种时，选择当前能容纳最多的袋子（“找最大的一个”），尽量把整叠聚到一处；
3. 装不下的剩余部分才继续放入下一个袋子。

所有容量按收纳袋真实重量计算（单袋总重 ≤ 64/64），不会超重；内嵌收纳袋按原版规则计重。

### 一键整理
- 面板底部的「一键整理」按钮，整理**袋内已有物品**（不收纳背包散落物）。
- 目标：让同种物品聚在一起并尽量填缝；必要时把某些袋子的内容撤离到其它袋子以腾出空间。
- 执行安全策略：
  - 整叠取出/放入，每个逻辑动作间隔 **2~5 tick**（防踢）；
  - 每个动作等待服务端把源袋/目标袋更新为预期内容后才继续（防幽灵物品）；
  - 超过 **1 秒**未确认则熔断，并按历史反向回滚；
  - **玩家任意输入立即中止**（不回滚），整理期间不锁 UI；
  - 进度显示在按钮上（如 `3/17`）。

### 容量显示
- 面板右下角显示 **已用 / 总量**：
  - 已用 = 各袋已用重量之和（单位 1/64）；
  - 总量 = 袋子数量 × 64，**恒定**，不随放入 16 堆叠/不可堆叠物品而变化。

## 环境要求

| 组件 | 版本 |
|---|---|
| Minecraft | 26.2 |
| Fabric Loader | >= 0.19.3 |
| Fabric API | 0.153.0+26.2 或兼容版本 |
| Java | >= 25 |

---

## 安装

1. 安装 Fabric Loader（>= 0.19.3）。
2. 将 [Fabric API](https://modrinth.com/mod/fabric-api) 与 `better-bundle-<version>.jar` 放入 `.minecraft/mods/`。
3. 启动游戏（仅客户端需要安装）。

发行版下载：见仓库的 **Releases** 页面。

---

## 从源码构建

```bash
./gradlew build
```

产物位于 `build/libs/`：

- `better-bundle-<version>.jar` — 安装用
- `better-bundle-<version>-sources.jar` — 源码

开发运行：

```bash
./gradlew runClient
```

## 已知限制

- **创造模式**：创造背包使用 `ItemPickerMenu`，其中 picker 槽位是动态重建且“无限”的，并包含破坏/垃圾桶槽。当前尚未针对创造模式做槽位白名单与禁用处理，可能出现搬错/复制/删除等问题，建议在生存模式使用。
- 一键整理当前只重排**袋内物品**，不会把背包散落物品收进袋子。
- 自动整理依赖服务端确认，整理较大规模物品时耗时较长（可随时手动打断）。
