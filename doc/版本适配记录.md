# 版本适配记录

记录各目标版本与 `main` 的差距，`main` 

基线为 Minecraft 26.2、mod 1.8.0。

## 目标 26.1 / 26.1.1 / 26.1.2

相对 `main`（26.2）只有两处差距。一是屏幕访问，26.1.x 要用 `client.screen`，不能用 `client.gui.screen()`，涉及 gui 与 mixin 下的几处调用。二是依赖，整套换成 26.1.x 的构件：MC 26.1.2、Fabric API 0.155.3+26.1.2、Cloth Config 26.1.154、ModMenu 18.0.2、loader 0.19.5，`fabric.mod.json` 的 `depends.minecraft` 相应改为 `>=26.1 <26.2` 等。Gradle/Loom 不动，输入与 Bundle API 也不用改。

## 目标 26.3

相对 `main`（26.2）差距如下。输入相关从直接调 GLFW 改为用 `InputConstants`（含键码常量，搜索框那几个裸键码一并替换）。Bundle 内容 API 由 `itemCopyStream()` 改名为 `itemCopies()`，`gui`、`sort`、`util` 下几处调用要跟着改。依赖整套换成 26.3 的构件：MC 26.3、Fabric API 0.162.0+26.3、Cloth Config 26.3.159、ModMenu 21.0.0、loader 0.19.5，`depends.minecraft` 改为 `>=26.3`。另外 Gradle 升到 9.8.1、Loom 升到 1.18.4。屏幕访问不用动。

## 目标 1.21.2（2026-10）

基线仍为 `main`（26.2），这是向下适配特例，改动只保留在 `1.21.x` 分支。

### 构建工具链
- Gradle 8.12.1、Loom 1.9.2、JDK 21（Loom 1.17/1.16 会把 1.21.2 当非混淆环境，无法用 Mojang mappings）
- 插件 ID 使用 `fabric-loom`；`mappings loom.officialMojangMappings()` 放在 `dependencies`
- 模组依赖必须用 `modImplementation`（1.21.2 是混淆版本，`implementation` 不会 remap）
- Access Widener 头使用 `named`（Loom 1.9 的目标命名空间）

### 依赖
- MC 1.21.2、Fabric API `0.106.1+1.21.2`、Cloth Config `16.0.143`、ModMenu `12.0.1`
- loader 最低 `0.16.7`（Fabric API 要求）
- `depends.minecraft` 暂定 `>=1.21.2 <1.21.3`；1.21.3 需要 Fabric API `0.114.1+1.21.3`，留给 Stonecutter 变体

### 代码差异
- 渲染：`GuiGraphicsExtractor` → `GuiGraphics`；`item/text/itemDecorations/setTooltipForNextFrame` → `renderItem/drawString/renderItemDecorations/renderTooltip`；`pushMatrix/popMatrix` → `pushPose/popPose`
- 输入：1.21.2 没有 `net.minecraft.client.input.*`，mixin 使用 `mouseClicked(double,double,int)`、`mouseReleased`、`mouseDragged(double,double,int,double,double)`、`keyPressed(int,int,int)`、`charTyped(char,int)`
- 屏幕访问：`client.gui.screen()` → `client.screen`
- 网络：`HashedStack`/`ContainerInput` → `ItemStack.EMPTY`/`ClickType.PICKUP`；点击包参数顺序与 `stateId` 按 1.21.2 调整
- Bundle：`itemCopyStream()`、`weight()` 一致；`removeOne()` 同样是移除整个选中条目
- 分类：`VegetationBlock`/`CactusFlowerBlock`/`LilyPadBlock` → `BushBlock`/`WaterlilyBlock`；1.21.2 无 `ItemTags.COPPER`、`ItemTags.SPEARS`
- 配置：`AutoConfigClient` → `AutoConfig.getConfigScreen`
- Mixin：`InventoryScreenMixin` 注入目标 `extractContents` → `render`（TAIL）

## 目标 1.21.3（2026-10）

1.21.2 的源码可直接编译，无需额外代码改动。

### 构建工具链
- 引入 Stonecutter 0.9.8 + loom-back-compat 0.4.3，Loom 升到 1.17.21，Gradle 9.5.1，仍用 JDK 21
- 版本登记在 `settings.gradle`，1.21.2 为基线和 `vcsVersion`
- 版本差异集中在 `versions/<版本>/gradle.properties`；源码共用根 `src`
- 产物名由 `base.archivesName` 生成：`better-bundle-mc<游戏版本>-v<mod版本>.jar`，发布时再补序号

### 依赖
- MC 1.21.3、Fabric API `0.114.1+1.21.3`、Cloth Config `16.0.143`、ModMenu `12.0.1`
- Cloth Config `17.x` 和 ModMenu `13.x` 是给 1.21.4 的，不要在 1.21.3 使用
- `depends.minecraft` 由 `minecraft_range` 按版本展开为 `>=1.21.3 <1.21.4`

### 验证
- `./gradlew build` 同时构建 1.21.2 与 1.21.3
- 1.21.3 实例需 Fabric API `0.114.1+1.21.3`、Cloth `16.0.143`、ModMenu `12.0.1`

## 目标 1.21.5（2026-10）

### 依赖
- MC 1.21.5、Fabric API `0.128.2+1.21.5`、Cloth Config `18.0.145`、ModMenu `14.0.2`
- `depends.minecraft` 展开为 `>=1.21.5 <1.21.6`

### 代码差异
- `ServerboundContainerClickPacket` 构造器改为 `(int containerId, int stateId, short slot, byte button, ClickType, Int2ObjectMap<HashedStack>, HashedStack carried)`
  - `slot` 需要显式转为 `short`
  - `carriedItem` 由 `ItemStack.EMPTY` 改为 `HashedStack.EMPTY`
  - 第 6/7 参数顺序与 1.21.4 相反：先 `changedSlots`，后 `carriedItem`
- 用 Stonecutter 条件注释 `//? if >=1.21.5` 区分，涉及 `BundlePanelInteraction` 与 `BundlePacketSender`
- 注意：`vcsVersion`（1.21.2）直接编译根 `src`，条件 `import` 会让 1.21.2 找不到类；1.21.5 分支使用全限定名 `net.minecraft.network.HashedStack`

### 验证
- `./gradlew build` 四个版本全部通过
- 1.21.5 实例使用 Fabric API `0.128.2+1.21.5`、Cloth `18.0.145`、ModMenu `14.0.2`，Loader 0.20.0

## 目标 1.21.6（2026-10）

### 依赖
- MC 1.21.6、Fabric API `0.128.2+1.21.6`、Cloth Config `19.0.147`、ModMenu `15.0.2`
- `depends.minecraft` 展开为 `>=1.21.6 <1.21.7`

### 代码差异
- 渲染矩阵：`GuiGraphics.pose()` 由 `PoseStack` 变为 `Matrix3x2fStack`
  - `pushPose()` / `popPose()` → `pushMatrix()` / `popMatrix()`
  - `translate(x, y, 0)` / `scale(s, s, 1)` → 2D 的 `translate(x, y)` / `scale(s, s)`
  - 涉及 `InventoryScreenMixin` 的悬浮放大
- Tooltip：`renderTooltip(Font, ItemStack, int, int)` 被移除，改用 `setTooltipForNextFrame(Font, ItemStack, int, int)`
  - 涉及 `BundlePanelRenderer`
- 两处都用 `//? if >=1.21.6` 条件注释区分

### 构建注意
- 并行构建多个版本时，`remapJar` 偶发 `Failed to create service instance`；用 `./gradlew build --no-parallel` 或单版本构建即可

### 验证
- 五个版本 `./gradlew build --no-parallel` 通过
- 1.21.6 实例使用 Fabric API `0.128.2+1.21.6`、Cloth `19.0.147`、ModMenu `15.0.2`，Loader 0.20.0
