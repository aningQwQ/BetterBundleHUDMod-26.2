# 版本适配记录

记录各目标版本与 `main` 的差距，`main` 

基线为 Minecraft 26.2、mod 1.8.0。

## 目标 26.1 / 26.1.1 / 26.1.2

相对 `main`（26.2）只有两处差距。一是屏幕访问，26.1.x 要用 `client.screen`，不能用 `client.gui.screen()`，涉及 gui 与 mixin 下的几处调用。二是依赖，整套换成 26.1.x 的构件：MC 26.1.2、Fabric API 0.155.3+26.1.2、Cloth Config 26.1.154、ModMenu 18.0.2、loader 0.19.5，`fabric.mod.json` 的 `depends.minecraft` 相应改为 `>=26.1 <26.2` 等。Gradle/Loom 不动，输入与 Bundle API 也不用改。

## 目标 26.3

相对 `main`（26.2）差距如下。输入相关从直接调 GLFW 改为用 `InputConstants`（含键码常量，搜索框那几个裸键码一并替换）。Bundle 内容 API 由 `itemCopyStream()` 改名为 `itemCopies()`，`gui`、`sort`、`util` 下几处调用要跟着改。依赖整套换成 26.3 的构件：MC 26.3、Fabric API 0.162.0+26.3、Cloth Config 26.3.159、ModMenu 21.0.0、loader 0.19.5，`depends.minecraft` 改为 `>=26.3`。另外 Gradle 升到 9.8.1、Loom 升到 1.18.4。屏幕访问不用动。

## 目标 1.21.2（2026-10）

基线仍为 `main`（26.2），这是向下适配特例，改动只保留在 `1.21.x` 分支。

### 构建工具链
- Gradle 8.12.1、Loom 1.9.2、JDK 21（Loom 1.17/1.16 会把 1.21.2 当非混淆环境，无法用 Mojang mappings）
- 插件 ID 使用 `fabric-loom`；`mappings loom.officialMojangMappings()` 放在 `dependencies`
- 模组依赖必须用 `modImplementation`（1.21.2 是混淆版本，`implementation` 不会 remap）
- Access Widener 头使用 `named`（Loom 1.9 的目标命名空间）

### 依赖
- MC 1.21.2、Fabric API `0.106.1+1.21.2`、Cloth Config `16.0.143`、ModMenu `12.0.1`
- loader 最低 `0.16.7`（Fabric API 要求）
- `depends.minecraft` 暂定 `>=1.21.2 <1.21.3`；1.21.3 需要 Fabric API `0.114.1+1.21.3`，留给 Stonecutter 变体

### 代码差异
- 渲染：`GuiGraphicsExtractor` → `GuiGraphics`；`item/text/itemDecorations/setTooltipForNextFrame` → `renderItem/drawString/renderItemDecorations/renderTooltip`；`pushMatrix/popMatrix` → `pushPose/popPose`
- 输入：1.21.2 没有 `net.minecraft.client.input.*`，mixin 使用 `mouseClicked(double,double,int)`、`mouseReleased`、`mouseDragged(double,double,int,double,double)`、`keyPressed(int,int,int)`、`charTyped(char,int)`
- 屏幕访问：`client.gui.screen()` → `client.screen`
- 网络：`HashedStack`/`ContainerInput` → `ItemStack.EMPTY`/`ClickType.PICKUP`；点击包参数顺序与 `stateId` 按 1.21.2 调整
- Bundle：`itemCopyStream()`、`weight()` 一致；`removeOne()` 同样是移除整个选中条目
- 分类：`VegetationBlock`/`CactusFlowerBlock`/`LilyPadBlock` → `BushBlock`/`WaterlilyBlock`；1.21.2 无 `ItemTags.COPPER`、`ItemTags.SPEARS`
- 配置：`AutoConfigClient` → `AutoConfig.getConfigScreen`
- Mixin：`InventoryScreenMixin` 注入目标 `extractContents` → `render`（TAIL）
